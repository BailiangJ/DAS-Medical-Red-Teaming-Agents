# Security policy

## Credentials

This repository must not contain API keys, access tokens, protected health information, or private evaluation data. Provider credentials are loaded from environment variables at runtime.

If a credential is committed, revoke it immediately and report the exposure privately to the maintainers.

## Reporting vulnerabilities

Please report security issues privately to the repository maintainers rather than opening a public issue containing exploit details or sensitive data.

## Evaluation data

Only synthetic or redistribution-approved fixtures belong in the repository. Do not submit real patient data, private prompts, provider logs, or generated outputs containing sensitive information.
