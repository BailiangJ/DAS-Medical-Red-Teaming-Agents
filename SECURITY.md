# Security policy

## Credentials

This repository must not contain API keys, access tokens, protected health information, or private evaluation data. Provider credentials are loaded from environment variables at runtime.

If a credential is committed, revoke it immediately and report the exposure through the repository's private security-reporting channel.

## Reporting vulnerabilities

Report security issues through the repository's private security-reporting channel; do not place exploit details or sensitive data in public issues.

## Evaluation data

Repository fixtures must be synthetic or covered by terms that permit redistribution. Do not submit real patient data, private prompts, provider logs, or generated outputs containing sensitive information.
